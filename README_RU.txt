SKINFORGE — ПОЛНЫЙ САЙТ С ОТДЕЛЬНОЙ КНОПКОЙ «ТЕСТ ЧЕК»

ВЕРСИЯ
- Основа: последняя полная версия index(6).html от 23.11.2026.
- Кнопка «✉ ТЕСТ ЧЕК» размещена прямо в верхней панели, сразу справа от «Вывод».
- Кнопка видна только после входа администратора; игрокам админская кнопка не показывается.
- Нажатие отправляет отдельное тестовое сообщение в Telegram-бот.
- Тест не создаёт заявку на подарок и не списывает баланс.
- Ограничение: один тест на проект за 24 часа, хранится в Upstash Redis.

ПЕРЕМЕННЫЕ VERCEL → Settings → Environment Variables
TELEGRAM_BOT_TOKEN
TELEGRAM_ADMIN_CHAT_ID
SKINFORGE_ADMIN_USERNAME
SKINFORGE_ADMIN_PASSWORD
SKINFORGE_ADMIN_SESSION_SECRET (минимум 32 случайных символа)
UPSTASH_REDIS_REST_URL
UPSTASH_REDIS_REST_TOKEN

Upstash URL и токен вводятся в Vercel Environment Variables, НЕ в HTML и НЕ в открытый GitHub.
Если подключение Upstash через интеграцию Vercel создало KV_REST_API_URL и KV_REST_API_TOKEN, API тоже поддерживает эти имена.

После загрузки файлов и добавления переменных сделай Redeploy в Vercel.
Сначала войди в админ-аккаунт на сайте. После этого рядом с кнопкой «Вывод» появится отдельная кнопка «ТЕСТ ЧЕК».


ИЗМЕНЕНИЕ ЦЕНЫ МИШКИ
Цена Мишки установлена в 0 в двух местах:
- index.html — отображение цены и списание игрового баланса;
- api/withdrawal.mjs — стоимость в сообщении администратору Telegram.
Для применения загрузите оба файла в GitHub с заменой существующих и выполните Redeploy в Vercel.


ПРОМОКОДЫ — НОВАЯ СИСТЕМА
- Золотая кнопка «ПРОМОКОДЫ» находится в верхней панели и в левом меню.
- SKIN5K — постоянный код на +5 000 игрового баланса; один раз на аккаунт.
- Администратор в окне «ПРОМОКОДЫ» может создать секретный код BEAR-XXXXXXXX. Он действует на 2 заявки на Мишку суммарно. Обычная кнопка Мишки также требует этот код; прямой обход через /api/withdrawal заблокирован.
- При активации кода на Мишку игрок указывает Telegram username; заявка сразу отправляется в Telegram администратору. Подарок выдаётся вручную.
- Каждый пятничный запуск Vercel Cron создаёт новый код на +10 000, действует 7 дней и один раз на аккаунт. Код отправляется в TELEGRAM_PROMO_CHAT_ID, а если переменная не задана — в TELEGRAM_ADMIN_CHAT_ID.

ДОБАВЬ В VERCEL ENVIRONMENT VARIABLES
CRON_SECRET = длинная случайная строка (минимум 32 символа)
TELEGRAM_PROMO_CHAT_ID = (необязательно) ID публичного канала/группы, куда бот может писать. Если не добавлять, уведомление пойдёт в TELEGRAM_ADMIN_CHAT_ID.

ПЯТНИЧНЫЙ CRON
- vercel.json вызывает /api/weekly-promo каждую пятницу в 12:00 UTC (примерно 19:00 по UTC+7).
- Cron запускается только в Production. На Hobby время может сдвигаться в пределах часа.

ВАЖНО О БАЛАНСЕ
Аккаунты SkinForge в этой версии хранятся в браузере, поэтому начисление 5 000/10 000 записывается в локальный игровой баланс текущего аккаунта. Upstash защищает общий лимит секретного кода на Мишку (2 активации) и повторную активацию кода на том же ID аккаунта. Для полноценной защиты баланса между устройствами и от создания дополнительных аккаунтов потребуется серверная авторизация игроков и серверное хранение их кошельков.


ПОЛЕ TELEGRAM ПОЛУЧАТЕЛЯ В ПРОМОКОДАХ
- Для промокодов на баланс (SKIN5K и пятничный бонус) Telegram username не нужен: поле скрыто, Telegram-заявка не отправляется.
- Для секретного промокода BEAR-... поле Telegram username показывается автоматически и обязательно. После ввода кода заявка на Мишку уходит в Telegram администратору.


UI UPDATE: ПРОМОКОДЫ отображаются только одной кнопкой в левом меню; кнопка возле «Вывод» убрана.


ОБЯЗАТЕЛЬНЫЙ ВХОД / РЕГИСТРАЦИЯ
- При первом открытии сайта без аккаунта автоматически открывается регистрация.
- Если в этом браузере уже есть созданный аккаунт, открывается форма входа.
- Закрыть окно и пользоваться сайтом без входа нельзя.
- После успешного входа или регистрации окно автоматически закрывается.
- Выход из аккаунта снова блокирует сайт до следующего входа.
- Важно: текущая система аккаунтов хранит профили в localStorage этого браузера;
  синхронизация между устройствами и серверная защита профилей не реализованы.
